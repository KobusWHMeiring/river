Space efficiency Medium — full-size emoji chars Excellent — 8px dots Low — text+bg padding per tag

Recommendation: Option B (Colored Dots) for the Active Sections list — most space-efficient, works well when sections have many activity types, and accessible via title attributes. Option C (Text Tags) is a close second if accessibility is prioritized. Option A (Icon Row) is visually appealing but harder to parse at small sizes and poor for screen readers.

🔍 Edge Cases & Open Questions

Still to resolve:
  1. Tasks with no template: Skip them? Or show a generic "custom" dot? Likely skip — no type = nothing to indicate.
  2. Rolling to-do items: Exclude entirely — they have no date and aren't planner-scheduled.
  3. Completed tasks: Should completed tasks still show as indicators? Yes — the activity is still planned/scheduled even if done.
  4. Sections with zero tasks this week: Show nothing (empty indicator area) — consistent with "no activity to report."
  5. TaskType.code values that aren't litter_run/weeding/planting/admin: Future task types should gracefully show a neutral dot or be silently skipped.
  6. Lifecycle stages with no active sections: Show progress bar as usual, no activity indicators.
  7. Admin tasks on Lifecycle bars: Are admin tasks meaningful here? Probably skip admin and only show field task types (litter, weed, plant) on lifecycle bars.
