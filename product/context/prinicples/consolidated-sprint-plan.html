Risk Register

Risk: bulk_create() Skips Model.save() Hooks

Severity: Medium  |  Task: 0.5  |  Mitigation: Audit Task model for signal handlers and custom save() logic before switching. If post_save signals are critical, trigger them manually after bulk_create, or use transaction.atomic instead.

Risk: Structured Logging Leaks Sensitive Data

Severity: Medium  |  Task: 1.3  |  Mitigation: Configure Sentry PII scrubbing. Review log messages for user data. Use Django's SensitivePostParameters in forms. Log at INFO level by default, DEBUG only in development.

Risk: ArchGuard False Positives Disrupt Workflow

Severity: Medium  |  Task: 2.1  |  Mitigation: Run in WARNING-only advisory mode (exit 0) for the first sprint. Review every flagged item. Tune exemptions before promoting to gating ERROR.

Risk: Adding .select_related() Breaks Lazy-Loading Assumptions

Severity: Low  |  Task: 1.1  |  Mitigation: select_related() is purely additive — it JOINs at query time. If a template accesses an FK that's NOT in select_related(), Django lazy-loads it as before. No breakage possible. Only risk is over-fetching unused columns (mitigate by only selecting the FK fields actually used in templates).

Risk: Performance Tests Flake on CI

Severity: Low  |  Task: 2.3  |  Mitigation: Use --reuse-db for consistent test DB state. Set budgets with 2-query headroom above Discovery actuals. Known-issues suppression for endpoints that legitimately vary (export).
